# Buscador de personajes de la serie Rick and Morty
En la serie de Rick and Morty hay muchos personajes que aparecen varias veces a lo largo de la serie, como hay tantos es dificl llevar una cuenta
de quien es el personaje y cual es su rol, sumado a que los personajes pueden tener variaciones, este buscador permite buscar un personaje por un nombre, puede ser aproximado, y te muestra su rol y en el caso de mi variente para el trabajo practico, su estado: vivo, muerto o desconocido
**Autor:** Luciano Gomez · Fundamentos de Desarrollo Web · UCSA

## Funcionalidades
- permite buscar personajes por nombre especifico o aproximado
- permite filtrar por el estado del personaje: vivo, muerto, desconocido
- permite filtrar por el genero del personaje: femenino, masculino, sin genero, desconocido

## Tecnologías
- HTML5, CSS3, JavaScript (ES6+), Fetch API, localStorage, API de Rick and Morty.
